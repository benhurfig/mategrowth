Pasta de campanha estática para GitHub Pages / Cloudflare Pages.

Arquivos:
- index.html (landing com 7 blocos, header, footer e formulário)
- privacidade.html
- css/style.css
- js/app.js
- assets/mategrowth-mark.webp (marca copiada da página de referência)

PUBLICAÇÃO:
1. Na raiz do repositório que já publica mategrowth.com, crie a pasta metodo-vagas-cheias.
2. Copie o CONTEÚDO desta pasta para ela, preservando as subpastas.
3. Faça git add, commit e push para o branch de publicação usado pelo site.
4. Se o projeto publicar a raiz via GitHub Pages, o endereço será:
   https://mategrowth.com/metodo-vagas-cheias/
   (somente após deploy e configuração existente do domínio).
5. Verifique a URL, os links, o formulário no celular e a política de privacidade.
